<p>Чтобы правильно подобрать оборудование для фонтана (насос) и трубопровод нужного диаметра, необходимо произвести расчёты,с учётом многих факторов. Рассмотрим порядок проведения гидравлических рассчётов на конкретном примере.</p>
<h2>Пример гидравлического рассчёта фонтана</h2>
<p><img loading="lazy" alt="" src="/img/netcat/userfiles/font001.JPG" /></p>
<p><em>Рисунок 1. Эскиз фонтана.</em></p>
<h3>Исходные данные</h3>
<ol>
<li>В проекте использовано три насадки <a href="/magazin/tovar/fontannaya-nasadka-schaumsprudler-1-1-2/" target="_blank" rel="noopener">Schaumsprudler 1 1/2&quot;</a>, высота струй - 2 м.</li>
<li>Длина всасывающей трубы - 7 м</li>
<li>Длина напорной трубы - 14 м (10 м+ 3 м+1 м)</li>
<li>Насос &quot;сухой&quot; установки</li></ol>
<h3>Порядок проведения рассчётов</h3>
<ol>
<li>Определение единичного расхода на насадку</li>
<li>Определение суммарного расхода на насадки</li>
<li>Определение напора на насадку</li>
<li>Определение диаметра трубы (из расчета скорости в напорном трубопроводе не более 3 м/с, во всасывающем - 2 м/с)</li>
<li>Определение гидравлических потерь на 1 п.м. трубопровода</li>
<li>Определение длины трубопровода</li>
<li>Определение приведенной длины трубопровода (с учетом местных сопротивлений)</li>
<li>Определение потерь по длине трубопровода</li>
<li>Определение коэффициента сопряжения (из расчета 5% на одну насадку с последующим прибавлением 1% на дополнительную насадку)</li>
<li>Определение необходимого напора</li>
<li>Определение насоса (по рассчитанным расходу и напору)</li></ol>
<h3>Расчёт гидравлических характеристик</h3>
<p>1. Определение единичного расхода на насадку. Расход на одну насадку определяется из гидравлических характеристик насадки</p>
<p><img loading="lazy" alt="" src="/img/netcat/userfiles/font002.JPG" /></p>
<p><em>Рисунок 2. Гидравлические характеристики насадки Schaumsprudler 1 1/2&quot;</em></p>
<p>Для выбранной насадки при высоте струи 2 м расход составляет Q = 183 л/мин.</p>
<p>2. Определение суммарного расхода на насадки. Суммарный расход на 3 насадки составляет - Q<sub>0</sub> = 3 x 183 = 549 л/мин.</p>
<p>3. Определение напора на насадку. Напор на насадку определяется так же по гидравлическим характеристикам (рис. 2), в нашем случае он составляет H = 4,5 м.</p>
<p>4. Определение диаметра трубы. Диаметр трубы определяется по таблице потерь давления в трубопроводах:</p>
<p><img loading="lazy" alt="" src="/img/netcat/userfiles/font003.jpg" /></p>
<p><em>Рисунок 3. Таблица потери давления в трубопроводах.</em></p>
<p>Для 549 л/мин по таблице получается труба диаметром&nbsp; D75 (2 1/2&quot;). Наше значение в таблице не отображено, поэтому данные берём для ближайшего большего значения (563 л/мин). Скорость потока в трубе по таблице 2,6 м/с, что соответствует требованиям (не больш 3 м/с для напорного трубопровода).</p>
<p>5. Определение гидравлических потерь на 1 п.м. трубопровода. Гидравлические потери по таблице (рис. 3) составляют i<sub>0</sub> = 0,105 м вод.ст./м.</p>
<p>6. Определение длины трубопровода. Длина трубопровода составляет L=7 м+14 м= 21 м (см. рис. 1 и пункты 2, 3 исходных данных)</p>
<p>7. Определение приведенной длины трубопровода. Приведённая длина трубопровода равна планируемой длине трубопровода (см. предыдущий пункт) плюс потери напора на задвижках, тройниках, уголках, кранах и т.п. (местные потери).</p>
<p>Местные гидравлические потери определяются по таблице:</p>
<p><img loading="lazy" alt="" src="/img/netcat/userfiles/font004.JPG" /></p>
<p><em>Рисунок 4. Таблица местных гидравлических потерь.</em></p>
<p>По эскизу фонтана (рис. 1) и таблице потерь (рис. 4) определяем потери и рассчитываем приведённую длину.</p>
<ul>
<li>поворот 90<sup>0</sup> (4 шт.) - 0,5 м на каждый</li>
<li>крестовина (1 шт.) - 3,0 м</li>
<li>задвижка (2 шт.) - 4,0 м на каждую</li>
<li>обратнй клапан (1 шт.) - 3,5 м</li></ul>
<p>L<sub>пр.</sub> = L + L<sub>поворот</sub>*4 шт.&nbsp; + L<sub>крестовина</sub> * 1шт. + L<sub>задвижка</sub> * 2шт. + L<sub>обратный клапан</sub> * 1шт.</p>
<p>&nbsp; L<sub>пр.</sub> = 21 + 0,5*4 + 3*1 + 4*2 + 3,5*1 = 37,5 м</p>
<p>8. Определение потерь по длине трубопровода. Гидравлические потери по длине рассчитываются по формуле:</p>
<p>h<sub>L</sub> = L<sub>пр.</sub>* i<sub>0</sub></p>
<p>h<sub>L</sub> = 37.5 * 0,105 &asymp; 3,94 м</p>
<p>9. Определение коэффициента сопряжения. Коэффициент сопряжения равен:</p>
<p>k = (100% +5% + 1% + 1%) / 100 = 1,07</p>
<p>10. Определение необходимого напора. Требуемый напор составляет:</p>
<p>H<sub>тр.</sub> = (H + h<sub>L</sub>) * k</p>
<p>H<sub>тр.</sub> = (4.5 + 3.94) * 1.07 &asymp; 9 м</p>
<p>11. Определение насоса (по рассчитанным расходу и напору). По нашим рассчётом получилось, что для нашего фонтана необходим насос с рабочей точкой:</p>
<p>Q<sub>0</sub> = 549 л/мин, H<sub>тр.</sub> = 9 м. По гидравлическим характеристикам насосов подбираем подходящую модель.</p>
