# Сайт «Гидрология» — новая версия

Статический сайт на [Astro](https://astro.build). После сборки получается папка `dist/` с обычными HTML, CSS и JS — её можно положить на любой хостинг, в том числе на Timeweb.

## Где что лежит

| Что | Файл |
| --- | --- |
| Все тексты, цифры, контакты, ссылки, фото | `src/data/site.json` |
| Главная страница (разметка) | `src/pages/index.astro` |
| Внутренние страницы | `src/pages/` (uslugi, proekty, publikatsii, sobytiya, galereya, video, partnery, kontakty, isparenie) |
| Решения (12 направлений) | `src/data/services.json` |
| Проекты | `src/data/projects.json` |
| Разделы галереи и видео | `src/data/gallery.json`, `src/data/video.json` |
| Тексты статей, событий, услуг | `src/content/publikatsii/`, `src/content/sobytiya/`, `src/content/uslugi/` |
| Импорт текстов из старой базы NetCat | `scripts/import-netcat.mjs` |
| Стили | `src/styles/global.css` |
| Интерактив: вода, вкладки, карта, схема, форма | `src/scripts/main.js` |
| Политика конфиденциальности | `src/pages/politika-konfidentsialnosti.astro` |
| Обработчик формы (отправка письма) | `public/send.php` |
| Настройки сервера, редиректы, безопасность | `public/.htaccess` |
| Логотипы, фавикон | `public/` |

## Как поменять текст или добавить фото

1. Откройте `src/data/site.json`.
2. Тексты меняются прямо в кавычках.
3. Фото: положите файл в `public/img/` и впишите путь в поле `photo` нужного элемента, например `"photo": "/img/hruschevo.jpg"`. Пока поле пустое, на сайте показывается цветная заглушка с подписью.
4. Пересоберите сайт (ниже).

Заглушки в квадратных скобках — `[__ м²]`, `[Имя Фамилия]`, `[Дата]` — нужно заменить реальными данными до запуска.

## Перенос содержимого со старого сайта

Тексты уже перенесены из дампа базы NetCat от 31.10.2026: 209 публикаций, 344 события, тексты 12 решений, 3 проекта, 14 разделов видео, альбомы галереи (≈1900 фото), партнёры, калькулятор испарения (формула старого сайта без изменений). Скрипт — `scripts/import-db.py` (нужен дамп, загруженный в локальный MySQL; запускать повторно только если база обновилась).

Картинки и видео лежат на хостинге в папке `netcat_files`. Список нужных файлов — `import/files-to-copy.tsv`. Скопировать их в проект:

```
python3 scripts/copy-images.py /путь/к/распакованной/netcat_files
npm run build
```

Пока файлов нет, на их месте видны цветные заглушки, а картинки в текстах скрываются.

**Форум** перенесён в статичный «Архив форума» (`/arhiv-foruma/`): 405 тем, 2691 сообщение. Скрипт — `scripts/import-forum.py` (дамп `co66690_forum` в локальной базе `f`). Переносятся только имя автора, дата и текст: e-mail, IP, подписи и личные сообщения — нет. Старые адреса `viewtopic.php?t=…` и `viewforum.php?f=…` перенаправляются на новые страницы.

**Что остаётся на хостинге и отдаётся оттуда** (не входит в `dist/`, не удалять при выкладке):
- `public_html/forum/files/` — 11 тыс. фото форума (≈3,7 ГБ); правила доступа — `public/forum/files/.htaccess`;
- `public_html/netcat_files/userfiles/video/` — видео (≈3 ГБ); правила — `public/netcat_files/.htaccess`.
Всё остальное от NetCat и phpBB (движок, `forum/*.php`, `netcat/`, кэш) после запуска удаляется.

## Сборка

Нужен Node.js 18 или новее.

```
npm install
npm run build
```

Готовый сайт появится в папке `dist/`. Посмотреть локально: `npm run preview`.

## Выкладка на Timeweb

1. Соберите сайт (`npm run build`).
2. Загрузите **содержимое** папки `dist/` (вместе со скрытым файлом `.htaccess`) в папку сайта `public_html` через файловый менеджер Timeweb или FTP.
3. В панели Timeweb проверьте, что включена отправка почты (функция `mail()`), и создайте ящик `no-reply@gidrologia.ru` — с него уходят заявки.
4. Отправьте тестовую заявку с сайта и проверьте, что письмо пришло на info@gidrologia.ru.

**Важно:** до запуска сохраните резервную копию текущего сайта (файлы и базы) в разделе «Резервные копии» Timeweb.
