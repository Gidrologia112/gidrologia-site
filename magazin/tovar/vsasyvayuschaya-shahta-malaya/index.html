Всасывающая шахта (малая) предназначена для установки насосов в безопасном каскадном водоёме. С помощью всасывающей шахты обеспечивается удобный монтаж насоса и доступ для его обслуживания.

Состав:

• наружный гофрированный слой ПНД (полиэтилен низкого давления)

• внутренний гладкий слой ПВД (полиэтилен высокого давления)

• крышка, дно ПНД (полиэтилен низкого давления)
