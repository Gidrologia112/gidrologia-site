Редактор26 сентября 2014

Декоративные водоёмы для стенда "Газпром" на Петербургском международном газовом форуме

Мы приступаем к созданию декоративных водоёмов с рыбой для стенда "Газпром" на Петербургском международном газовом форуме, который пройдет с 7 по 10 октября 2014 г.

Это будет четыре искусственных водоёма одинаковой формы, высотой 40 см. и площадью 22 кв.м каждый. Водоёмы будут заселены дорогими породами декоративной рыбы.

Редактор26 сентября 2014

Монтируем геотекстиль в короба будущих водоемов. Работы проводим совместно с нашими партнерами из Кирова - ландшафтной компанией "Фрея".

Редактор26 сентября 2014

Монтаж гидроизоляции завершён

Редактор27 сентября 2014

Закончен монтаж гидроизоляции.
Смонтированы герметичные проходы для кабеля.

Редактор27 сентября 2014

Начало работ по декорации искусственных водоёмов.
Используются валуны и речной гравий

Редактор27 сентября 2014

Монтаж оборудования.
Насосы монтируются под фальш-камнями, которые будут размещены внутри водоемов.

Редактор27 сентября 2014

Над водоёмами смонтирован временный защитный купол из геотекстиля.

Он предназначен для защиты водоёмов от пыли и грязи. А так же для создания парникового эффекта для формирования необходимой температуры для посадки растений и рыбы.

Редактор30 сентября 2014

Посадка растений

Редактор5 октября 2014

Редактор12 октября 2014

Итак, мы сделали это - Декоративные водоёмы построены во время в сжатые сроки, на должном высоком уровне качества.
Можно сказать, что была проверка мобильности и работоспособности компании. Срок открытия выставки не передвинуть, поэтому все проблемы, появляющиеся во время монтажа, должны решаться сверхоперативно, чтобы не подвезти заказчиков. И мы с этим справились.

Так что пожалуйста, еще одно направление деятельности компании "Гидрология" имеет место быть. Готовы соорудить Вам декоративные водоёмы для выставок любой сложности и на высоком уровне!
