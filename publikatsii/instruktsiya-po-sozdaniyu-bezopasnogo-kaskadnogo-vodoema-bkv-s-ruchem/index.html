19 мая 2015 Безопасные каскадные водоёмы

Основными преимуществами безопасного каскадного водоёма (БКВ) являются разнообразие внешнего вида и быстрота монтажа.

Безопасный каскадный водоём может быть фонтаном, ручьем, каскадом.

В статье "Инструкция по создания Безопасного каскадного водоёма (БКВ)" мы рассказывали о процессе создания безопасного каскадного водоёма с фонтаном.

В этой статье мы расскажем о том, как создать безопасный каскадный водоём с ручьём.

Инструкция по созданию безопасного каскадного водоёма (БКВ) с ручьём.

1. Выбираем на участке место для безопасного каскадного водоёма. Размечаем контуры. Ручей будет длиной 12 м. Изогнутой формы. С небольшим перепадом по высоте только для естественного течения. Излив через фонтанную насадку.

2. Вынимаем грунт, организуя русло ручья и выкапываем приёмный котлован для воды. По расчётам объем приёмного котлована, при длине ручья 12 м и спокойном течении, должен быть равен 1.5 м3.

3. Подготовленное русло и котлован выкладываем геотекстилем и производим монтаж гидроизоляции.

4. Устанавливаем насосную камеру в приёмном котловане, монтируем в нее насос, прокладываем кабель и шланги, устанавливаем насадку-излив, организуем крановые боксы с размещением кранов для зимней консервации БКВ.

После установки оборудования приёмный котлован послойно заполняется гравией разных фракций.

5. После монтажа оборудования и засыпки приёмного котлована безопасный каскадный водоём заполняется водой и производится пробный запуск системы.

После проверки производятся работы по декорации русла ручья.

6. Не отключая циркуляцию воды, для того, чтобы нагрузка на русло ручья была максимальной, производят подрезку лишней гидроизоляции. После этого производят отсыпку поля инфильтрации вдоль русла ручья.

7. Производится финальная проверка работоспособности системы безопасного каскадного водоёма перед проведением работ по чистовой отделке зоны БКВ.

8. Декорируется прилегающая к безопасному каскадному водоёму территория.

Строительство БКВ с ручьём завершено!
